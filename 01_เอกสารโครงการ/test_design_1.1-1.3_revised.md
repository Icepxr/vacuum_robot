# ออกแบบการทดสอบใหม่ (ฉบับปรับปรุง) — หัวข้อ 1.1–1.3

เอกสารนี้ **แทนที่เฉพาะหัวข้อ 1.1–1.3** ในไฟล์ `project_next_steps_plan.md` เดิม (หัวข้อ 1.4 Scissor Lift และ 1.5 ทดสอบรวมระบบ ยังใช้แผนเดิม) ปรับตามข้อมูลอุปกรณ์จริงและแนวทางที่คุณยืนยันมา:

- **1.1** เปลี่ยนวัตถุทดสอบเป็นก้อน PLA พิมพ์ 3D ขนาด 5×5×5 mm (จากเดิมข้าวสาร/ทราย) — ใช้มอเตอร์ดูด AVC BA10033B12U (12V, 2.4A) ตัวจริง
- **1.2** ต้องประกอบล้อ+ออกแบบระบบควบคุมก่อนถึงจะทดสอบได้จริง — เพิ่มขั้นตอนเตรียมความพร้อม (Prerequisite) ก่อนตารางทดสอบ
- **1.3** ยืนยันใช้มอเตอร์เหลือง (Yellow Motor) หมุนแปรง — เพิ่มการบันทึกแรงดันจริงที่จ่าย เพราะมอเตอร์ตัวนี้พิกัด 3–5V แต่ระบบจ่ายไฟหลักอยู่ที่ ~11–12V

---

## 1.1 การทดสอบมอเตอร์ดูดฝุ่น (Suction Motor Test) — ฉบับปรับปรุง

**อุปกรณ์จริง:** AVC BA10033B12U — 12V, 2.4A (28.8W), blower centrifugal 97mm — เป็นตัวดึงกำลังไฟสูงสุดในระบบ (~45% ของงบพลังงานรวม) ดังนั้นตัวเลขจากการทดสอบนี้จะกระทบทั้งการเลือก MOSFET/driver และการคำนวณ battery budget โดยตรง

### ทำไมเปลี่ยนมาใช้ก้อน PLA 5×5×5mm

ข้าวสาร/ทรายมีปัญหาเรื่อง**ควบคุมตัวแปรไม่ได้**: ขนาด/น้ำหนักแต่ละเม็ดไม่เท่ากัน ดูดความชื้นได้ ผลทดสอบไม่ repeatable ระหว่างรอบ ก้อน PLA พิมพ์เองแก้ปัญหานี้ตรงๆ — ขนาดคงที่ทุกก้อน, ควบคุมมวลได้ผ่าน infill %, ไม่เปลี่ยนสภาพระหว่างการทดสอบซ้ำหลายรอบ และ**นับจำนวนได้แม่นยำกว่าชั่งน้ำหนัก**เพราะเป็นวัตถุแยกชิ้นรูปทรงเดียวกัน (ต่างจากฝุ่น/เศษที่ต้องชั่งเพราะนับไม่ได้)

**ข้อกำหนดตัวทดสอบ:**

| รายการ | ค่าที่แนะนำ |
|---|---|
| ขนาดก้อน | 5×5×5 mm (คงที่ตามที่ระบุ) |
| Infill การพิมพ์ | กำหนดค่าเดียวคงที่ทุกก้อน (เช่น 100% หรือ 20% — เลือกค่าไหนก็ได้ แต่ **ต้องเหมือนกันทุกก้อน** เพื่อให้มวล/ความหนาแน่นสม่ำเสมอ) |
| จำนวนที่ต้องพิมพ์ | อย่างน้อย 60–80 ก้อน (ใช้ทดสอบได้ 6–8 รอบ รอบละ 10 ก้อน) |
| การสุ่มตรวจมวล | ชั่งสุ่ม 10 ก้อนจากชุดที่พิมพ์ ก่อนเริ่มทดสอบ บันทึกค่าเฉลี่ย±ส่วนเบี่ยงเบน เพื่อยืนยันว่าก้อนสม่ำเสมอพอ (ถ้าเบี่ยงเบนเกิน ~5% ให้ตรวจการพิมพ์ใหม่) |

### ตารางที่ 1: กระแส/แรงดันขณะทำงาน (คงเดิมจากแผนก่อน)

| รายการ | รายละเอียด |
|---|---|
| Objective | วัดกระแสจริงเทียบพิกัด 2.4A ของ AVC BA10033B12U และแรงดัน manometer |
| Setup | ต่อ blower เข้า 12V ตรง (หรือผ่านวงจรขับจริงที่จะใช้ในระบบ) วัดกระแสด้วย multimeter/current sensor แบบ inline, ต่อ manometer วัดแรงดัน static |
| **เช็คก่อนทดสอบ** | ยืนยันว่า MOSFET/driver ที่ใช้ขับ blower เป็น **logic-level** (เปิดสุดได้ที่ 3.3V จาก ESP32) — MOSFET ทั่วไปอย่าง IRF520 ต้องการ Vgs ~10V ถึงจะนำกระแสเต็มที่ ถ้าขับตรงจาก GPIO 3.3V จะร้อนเกินและกินไฟเกินจริง ให้ตรวจสอบ/เปลี่ยนก่อนวัดค่า |
| เกณฑ์ผ่าน | กระแสวัดได้ใกล้เคียง 2.4A ที่ระบุ (ไม่เกิน 2.4A × 1.15 = 2.76A ถ้าเกินมากแปลว่า driver มีปัญหา ไม่ใช่ตัวมอเตอร์) |

### ตารางที่ 2: ประสิทธิภาพเก็บก้อน PLA (แทนตารางเดิม)

| คอลัมน์ | คำอธิบาย |
|---|---|
| Trial | หมายเลขรอบ |
| พื้นผิว | กระเบื้อง / พรมบาง / ไม้ ฯลฯ |
| จำนวนก้อนทั้งหมด (ชิ้น) | จำนวนที่วางทดสอบ (แนะนำ 10 ก้อน/รอบ) |
| รูปแบบการวาง | เรียงเส้นตรง / กระจายสุ่ม / กองรวม (ทดสอบหลายแบบ) |
| ระยะห่างหัวดูดจากก้อน (mm) | ระยะเริ่มต้นก่อนดูด |
| เวลาที่ใช้ดูด (s) | คงที่ทุกรอบ (เช่น 10s) เพื่อเทียบกันได้ |
| จำนวนที่ดูดเก็บได้ (ชิ้น) | นับจริงจากถังฝุ่นหลังทดสอบ |
| **% เก็บได้ (นับจำนวน)** | = จำนวนที่เก็บได้ ÷ จำนวนทั้งหมด — **นับชิ้น ไม่ต้องชั่งน้ำหนัก** |
| ผ่านเกณฑ์ (≥80%) | อัตโนมัติ |

เกณฑ์ผ่านคงไว้ที่ ≥80% เหมือนแผนเดิม แต่ตอนนี้แม่นยำกว่าเพราะนับจำนวนก้อนที่เท่ากันทุกชิ้นแทนการชั่งน้ำหนักเศษที่ไม่สม่ำเสมอ

## 1.2 การทดสอบการขับเคลื่อน (Locomotion Test) — ฉบับปรับปรุง พร้อมขั้นตอนเตรียมความพร้อม

คุณระบุว่ายังไม่ได้ประกอบล้อกับตัวหุ่น และยังไม่ได้ออกแบบระบบควบคุม — เท่ากับว่า**ทดสอบข้อนี้ยังทำไม่ได้ทันที** ต้องผ่าน 3 ขั้นเตรียมการก่อน ถึงจะเริ่มเก็บข้อมูลตามตารางเดิมได้จริง

### ขั้นเตรียมความพร้อม (Prerequisites) — ต้องทำให้เสร็จก่อนเข้าตารางทดสอบ

| ขั้น | งานที่ต้องทำ | ผลลัพธ์ที่ต้องได้ |
|---|---|---|
| 0.1 | ประกอบมอเตอร์ JGB37-520 (12V, 0.65A) พร้อมล้อ เข้ากับฐานหุ่นจริง 2 ตัว (ซ้าย-ขวา) | ล้อหมุนได้อิสระ ไม่ติดขัดกับโครง |
| 0.2 | เดินสายไฟ ESP32 ↔ TB6612FNG ↔ มอเตอร์ทั้งสอง + ต่อ encoder เข้า ESP32 | วงจรครบ พร้อมจ่ายไฟ |
| 0.3 | เขียนเฟิร์มแวร์ขั้นต่ำ (ยังไม่ต้องมี FSM เต็มรูปแบบ): สั่งเดินหน้า/ถอยหลัง/เลี้ยวซ้าย-ขวาแบบ open-loop (PWM คงที่) + อ่านค่า encoder ออก serial monitor ได้ | หุ่นเคลื่อนที่ตามคำสั่งพื้นฐานได้ และเห็นค่า encoder เปลี่ยนตามจริง |

**ข้อควรระวังจากสเปกจริง:** TB6612FNG รับกระแสต่อเนื่องได้ ~1.2A และพีค 3.2A ต่อช่อง ส่วน JGB37-520 ระบุกระแสทำงานปกติ 0.65A แต่กระแสตอน stall (ล้อติด/ออกตัว) ของมอเตอร์เกียร์ตระกูลนี้มักสูงกว่า 3–5 เท่า (~2–3A) ซึ่ง**ใกล้เคียงขีดจำกัดพีคของ TB6612FNG** — ตารางที่ 3 ด้านล่าง (กระแส stall) จึงสำคัญมาก ต้องวัดจริงก่อนสรุปว่า driver ตัวนี้พอใช้ไหม ถ้า stall เกิน ~2.5A ต่อเนื่องควรเปลี่ยนไปใช้ driver ที่กระแสสูงกว่า (เช่น DRV8871 หรือมอดูลคู่ที่รองรับ ≥3A ต่อเนื่อง)

### ตารางทดสอบ (เหมือนแผนเดิม ใช้ได้หลังผ่าน Prerequisite ครบ)

ตารางที่ 1 (Odometry), ตารางที่ 2 (ข้ามธรณีประตู), ตารางที่ 3 (กระแสมอเตอร์ขับ — **เพิ่มความสำคัญ** ตามเหตุผลข้างบน), ตารางที่ 4 (เซนเซอร์กันตก/กันชน) — ใช้โครงสร้างเดิมจากแผนก่อนหน้าได้ทั้งหมด ไม่ต้องแก้ไข

## 1.3 การทดสอบกลไกปัดกวาด (Cleaning Test) — ฉบับปรับปรุง

**ยืนยันอุปกรณ์:** Yellow Motor (มอเตอร์เหลือง) หมุนแปรงข้าง — พิกัดจากตารางสเปก **3–5V, ~1A, 2–5W**

**ประเด็นสำคัญที่ต้องบันทึกเพิ่ม:** ระบบจ่ายไฟหลักของหุ่นอยู่ที่ระดับ ~11–12V (ตามข้อเสนอแบตในหัวข้อถัดไป) แต่มอเตอร์เหลืองพิกัดแค่ 3–5V — ถ้าจ่ายเต็ม 12V ตรงๆ จะ**เกินพิกัดเกือบ 3 เท่า มอเตอร์ไหม้แน่นอน** ต้องขับผ่าน PWM แบบจำกัด duty cycle (เช่น ~30–40% ของ 12V ≈ เฉลี่ย 3.6–4.8V) หรือใช้ buck/LDO แยกจ่าย 5V ให้มอเตอร์นี้โดยเฉพาะ — เพิ่มคอลัมน์บันทึกไว้ในตารางเพื่อให้รู้ว่าค่า RPM/แรงปัดที่วัดได้มาจากการตั้งค่าไฟแบบไหน

### ตารางทดสอบ

| คอลัมน์ | คำอธิบาย |
|---|---|
| Trial | หมายเลขรอบ |
| พื้นผิว | กระเบื้อง / พรมบาง / ไม้ |
| ชนิดเศษวัสดุ | เศษฝุ่น/เส้นผม/กระดาษเล็ก (หรือใช้ก้อน PLA 5×5×5mm ชุดเดียวกับข้อ 1.1 เพื่อเทียบผลแบบ apples-to-apples ก็ได้) |
| **แรงดันไฟที่จ่ายจริง (V)** | *ใหม่* — วัดแรงดันเฉลี่ยที่มอเตอร์ได้รับจริงขณะทดสอบ |
| **Duty Cycle PWM (%)** | *ใหม่* — ถ้าขับผ่าน PWM ให้บันทึกค่า duty ที่ตั้ง |
| โหมดทดสอบ | แปรงอย่างเดียว / แปรง+ดูด |
| น้ำหนักก่อน (g) | |
| น้ำหนักเศษเหลือ (g) | |
| % เก็บได้ | คำนวณอัตโนมัติ |
| ผ่าน (≥80% เมื่อโหมด แปรง+ดูด) | คำนวณอัตโนมัติ |

**ทดสอบเพิ่มที่แนะนำ:** วัดกระแสมอเตอร์เหลืองที่ duty cycle ต่างกัน 2–3 ระดับ (เช่น 30%, 50%, 70%) เพื่อหาจุดที่แรงปัดพอดีโดยไม่เกินพิกัดกระแส ~1A ของมอเตอร์ — ผลตรงนี้จะใช้ตั้งค่าเริ่มต้นในเฟิร์มแวร์ตอนออกแบบ System Program ต่อไป

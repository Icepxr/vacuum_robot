# คู่มือใช้งานและแผนที่โค้ด MRC-001 — ฉบับ 18 ก.ย. 2026

อ่านหน้านี้หน้าเดียวพอสำหรับ "ใช้หุ่น" · ถ้าจะ "แก้หุ่น" ค่อยตามลิงก์ไปไฟล์ที่ระบุ

## 1. ภาพรวม 30 วินาที

หุ่นมี 3 ส่วนที่คุยกันเป็นสายโซ่ — **ส่วนไหนเงียบเกิน 0.3 วิ ล้อหยุดเอง**

| ส่วน | อยู่ที่ไหน | ทำอะไร | โค้ดอยู่ที่ |
|---|---|---|---|
| **มือถือ/โน้ตบุ๊ก** | มือคุณ | หน้าเว็บขับ: จอย · ภาพสด · ปุ่มถ่าย/ดูด · ตั้งค่า | `11_pi5_vision/src/static/drive.*` |
| **Pi 5** | บนหุ่น | เว็บเซิร์ฟเวอร์ · กล้อง · อ่านตัวเลข (OCR) · จดข้อมูล · แปลคำสั่งส่งต่อให้ ESP32 | `11_pi5_vision/src/*.py` |
| **ESP32-S3** | บนหุ่น | ล้อ · เสาเซอร์โว · ดูด/แปรง · กันอันตราย (deadman, watchdog, จำกัดกระแส) | `src/robot/*` |

Pi กับ ESP32 คุยกันด้วยสาย UART 3 เส้น (`GPIO43→pin10` · `GPIO44←pin8` · `GND pin6`) ภาษาที่คุยคือเฟรมสั้นๆ เช่น `$V,12,150,0*3A` (Pi สั่งความเร็ว) / `#T,…` (ESP32 รายงานทุก 0.1 วิ) — นิยามอยู่ที่ `11_pi5_vision/src/mrc_protocol.py` (ฝั่ง Pi) และ `src/robot/comm.cpp` (ฝั่ง ESP32)

## 2. ใช้งานประจำวัน — 5 ขั้น

1. **เปิด Personal Hotspot บน iPhone** (ชื่อ `دياس`) และเปิดหน้านั้นค้างไว้จนหุ่นต่อติด
2. **เสียบไฟ Pi** (ESP32 ได้ไฟจาก USB-C ของ Pi) → รอ ~50 วิ เว็บขึ้นเอง ไม่ต้องสั่งอะไร
3. **มือถือ/Mac ต่อ hotspot เดียวกัน** แล้วเปิด **`http://uchida-pi5.local:8000/drive`**
4. ดูแถบบน: ต้องเห็น **"พร้อม"** + **"ลิงก์ ~100 ms"** + **"กล้อง ปกติ"** — ครบ 3 = ขับได้
5. ขับด้วยจอยซ้าย (นิ้วโป้ง) หรือ WASD · ปุ่มแดงกลม = E-STOP · ปุ่ม "ถ่าย" = ถ่าย+อ่านตัวเลข (ผล ~0.2 วิ ในแถบล่าง) · **แผงกล้อง** (ซ้ายกลางจอ): ปุ่ม ▲▼ "มุมกล้อง" (ก้ม-เงย) และ "เสา" (scissor) — **แตะ = ขยับ 1 ขั้น · กดค้าง = เดินต่อเนื่อง ปล่อยแล้วหยุด** · แถบสีบอกตำแหน่งจริง · ปุ่ม กลาง/พับ/ปล่อย — ⚠ ตั้งขีดจำกัดเสาในแท็บกล้องให้ตรงกลไกก่อนใช้จริง

ปิดงาน: ถอดไฟได้เลย (ไม่ต้อง shutdown — ข้อมูลเขียนลง SD ทันทีทุกครั้งที่ถ่าย) · ถ้าเปลี่ยนหน้า/พับมือถือ หุ่นหยุดเองใน 0.3 วิ

### ตั้งค่าบนหน้าเว็บ (ปุ่ม ⚙ มุมขวาบน · จำค่าไว้ในเครื่องนั้น)
| แท็บ | ที่ปรับบ่อย |
|---|---|
| ขับ | **เพดานความเร็วสูงสุด** (เริ่ม 150 mm/s · ยกได้ถึง 716 — ยิ่งเร็วยิ่งวิ่งต่อไกลก่อนหยุดทัน ดูตาราง §4) · ความไวหมุน · ความนุ่มออกตัว · กลับทิศ |
| กล้อง | fps ภาพสด · **ลากกรอบบนภาพ = บอกว่าตัวเลขมิเตอร์อยู่ตรงไหน** (บันทึกลง `roi_config.json` บน Pi) |
| ทำความสะอาด | % ดูด · % แปรง (สูงสุด 40 — ล็อกด้วยเหตุผลไฟฟ้า) · เปิดดูดอัตโนมัติตอนขับ |
| การเตือน / จอ / ปุ่ม / สถานะ | เสียง สั่น ขนาดจอย สี ฯลฯ |

## 4. ตัวเลขที่ควรรู้ตอนขับ (วัดจริง 16 ก.ย. · ไฟล์ 19 §19.8)

| เพดานความเร็ว | หุ่นวิ่งต่อหลังคุณเห็นสิ่งกีดขวาง (ภาพ+คน+ระบบ+เบรก) |
|---:|---|
| 150 mm/s (ค่าเริ่มต้น) | ~85–130 mm ≈ 1 ช่วงล้อ |
| 300 | ~185–285 mm |
| 716 (สูงสุด) | ~585–815 mm — เกือบ 1 เมตร |

ไม่มีกันชน/เซนเซอร์ระยะแล้ว (ตัดออกตาม C26) — **คนขับคือเซนเซอร์เดียว**

## 5. แผนที่โค้ด — ไฟล์ไหนทำอะไร

### เฟิร์มแวร์ ESP32 (`src/` · บิลด์ด้วย PlatformIO env `robot`)
| ไฟล์ | ทำอะไร | แตะเมื่อ |
|---|---|---|
| `src/robot/main.cpp` | `setup()/loop()` ของหุ่น · คอนโซล USB (`?` ดู help) · watchdog · เรียก tick ของทุกโมดูล | เพิ่มคำสั่งคอนโซล |
| `src/robot/comm.cpp/.h` | UART ไป Pi: รับ `$V $S $E $C $P $L` ตอบ `#A/#N` · ส่ง `#T` 10 Hz · `#E` เหตุการณ์ | เพิ่มคำสั่งใหม่ระหว่าง Pi–ESP32 |
| `src/robot/comm_codec.h` | CRC-8 + รูปแบบเฟรม (ไม่พึ่ง Arduino → เทสบน Mac ได้) | แทบไม่ต้อง |
| `src/robot/manual_core.h` + `manual.cpp` | โหมดขับเอง: แปลง (v, ω) → duty ล้อซ้าย/ขวา · slew · deadman · เพดานที่ผู้ใช้ตั้ง · R2 หน่วงดูด | ล้อกลับด้าน / ปรับความนุ่ม / เปลี่ยนกติกา |
| `src/robot/mission_core.h` + `mission.cpp` | ภารกิจอัตโนมัติ 1 รอบ (เดิน→ยกเสา→ถ่าย→พับ→เดิน) — **ยังไม่ได้ใช้ในแมนวล** | เฟสอัตโนมัติ |
| `src/robot/wdt.h` | task watchdog 1 s (ค้าง → รีบูต → ล้อ coast) | ไม่ต้อง |
| `src/motor_encoder_test/` `servo_test/` `blower_test/` | ชุดทดสอบ M1/M2/M3 เดิม — เฟิร์มแวร์รวมเรียกฟังก์ชันจากที่นี่ (`motorSetLR`, `servoMissionMove`, `blowerCommand`) | ขา GPIO / PWM / พิกัดฮาร์ดแวร์ |
| `test/host_*.cpp` | เทสบน Mac ด้วย clang++ (codec · manual · mission) | ทุกครั้งที่แก้ `*_core.h` |

## 6. คำสั่งสำหรับคนแก้โค้ด (บน Mac ในโฟลเดอร์โปรเจกต์)

```bash
# แก้โค้ด Pi แล้วส่งขึ้นหุ่น + รีสตาร์ทเว็บ
bash 11_pi5_vision/scripts/deploy_to_pi.sh && ssh uchida@uchida-pi5.local 'sudo systemctl restart mrc-web'
```
```bash
# รันเทสบน Pi
ssh uchida@uchida-pi5.local 'cd ~/mrc && source .venv/bin/activate && python -m pytest -q tests'
```
```bash
# แก้เฟิร์มแวร์ ESP32 แล้วแฟลช (บิลด์บน Pi ผ่าน USB-C · ต้องหยุดเว็บก่อนเพราะแย่ง UART)
rsync -az --exclude secrets.h src/ uchida@uchida-pi5.local:~/mrc-fw/src/ && ssh uchida@uchida-pi5.local 'sudo systemctl stop mrc-web; cd ~/mrc-fw && source ~/mrc/.venv/bin/activate && pio run -e robot -t upload --upload-port /dev/ttyACM0; sudo systemctl start mrc-web'
```
```bash
# เทสเฟิร์มแวร์บน Mac (ไม่ต้องมีบอร์ด)
clang++ -std=c++17 -I src/robot test/host_manual.cpp -o /tmp/m && /tmp/m
```
```bash
# ดู log เว็บสด
ssh uchida@uchida-pi5.local 'journalctl -u mrc-web -f'
```

## 7. สิ่งที่ยังไม่ได้ทำ / ยังไม่พิสูจน์ (ณ 18 ก.ย.)
- ยังไม่เคยขับล้อจริงจากหน้าเว็บ (ทดสอบแค่ลิงก์ตอบรับ) — ทิศทางอาจกลับด้าน
- OCR ทดสอบกับลายมือชุดเดียว (1509 ปากกาแดง) — มิเตอร์จริงในสนามยังไม่เห็น
- โหมดภารกิจอัตโนมัติ (mission) ต้องการค่าตำแหน่งเสาจริง
- แบต/กระแสยังไม่ส่งใน `#T` (ADC ยังไม่ทำ) · เซนเซอร์อากาศ ENS160 ยังไม่ต่อ
- HTTPS (จอยเกม/กันจอดับ) · Pi เป็น hotspot เองสำหรับสนาม · ฐานข้อมูลคลาวด์

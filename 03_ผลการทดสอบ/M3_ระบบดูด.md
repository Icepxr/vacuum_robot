## 4. เช็คลิสต์ก่อนจ่ายไฟ 12 V

- ☐ ยืนยันว่า MOSFET เป็น **logic-level** (ทำ S0 ก่อน)
- ☐ **pull-down 10 kΩ ที่เกตติดตั้งแล้ว** — ไม่มีตัวนี้ blower จะออกตัวเองตอน ESP32 บูต
- ☐ ไดโอด SS34 ขั้วถูกด้าน (ต่อกลับด้าน = ลัดวงจรทันทีที่จ่ายไฟ)
- ☐ GND ทั้งสามจุดต่อถึงกัน
- ☐ **ตั้ง current limit ของแหล่งจ่ายที่ 4.0 A** — สูงกว่าเกณฑ์ผ่าน 2.76 A พอให้ inrush ผ่านได้ แต่ยังต่ำพอที่จะตัดถ้าลัดวงจร
- ☐ ยึด blower ให้แน่น ไม่วางลอย (ตอนออกตัวมีแรงบิดสะบัด)
- ☐ ไม่มีอะไรอยู่หน้าช่องดูด/ช่องลมออก

### S0 — ยืนยันว่า MOSFET เป็น logic-level (ยังไม่จ่ายไฟ 12 V)

แผนเทส §1.1 เตือนไว้ตรงๆ ว่า MOSFET ทั่วไปอย่าง IRF520 ต้องการ V_gs ~10 V ถ้าขับตรงจาก GPIO 3.3 V จะไม่เปิดสุด → ร้อนเกินและกินไฟเกินจริง

|---|---|---|
| เบอร์ที่พิมพ์บนตัวถัง | ______________ | ต้องเป็นรุ่น logic-level เช่น IRLZ44N (ตัว **L** สำคัญ) |
| datasheet ระบุ R_DS(on) ที่ V_gs = 4.5 V หรือต่ำกว่าไหม | ☐ มี ☐ ไม่มี | **ถ้าไม่มี = ไม่ใช่ logic-level ห้ามใช้** |

**ถ้าไม่ผ่าน S0 ให้หยุด** — เปลี่ยน MOSFET ก่อน อย่าเทสต่อ เพราะทุกตัวเลขหลังจากนี้จะผิดหมด

### S2 — อุณหภูมิ MOSFET *(ขั้นสำคัญที่สุด — ตรวจสอบค่าที่เดาไว้)*

พิมพ์ **`heat 6`** (เปิดค้าง 6 นาที) แล้ววัดอุณหภูมิผิว MOSFET ทุก 1 นาที จนค่านิ่ง (ไม่เพิ่มเกิน 1 °C ใน 2 นาที)
เฟิร์มแวร์จะขึ้นเวลาที่ผ่านไปทุก 30 วินาที และ**กดปุ่มใดก็ได้แล้ว Enter เพื่อหยุดกลางคัน**

> **ทำไมไม่ใช้ `on`:** คำสั่ง `on` ตัดเองที่ 2 นาที ซึ่งยังไม่ถึงสถานะคงตัวทางความร้อน
> และถ้าปล่อยให้ตัดแล้วสั่งใหม่ MOSFET จะเย็นลงระหว่างนั้น ทำให้วัดค่านิ่งไม่ได้เลย

| เวลา | อุณหภูมิผิว MOSFET | อุณหภูมิห้อง |
|---|---|---|
| 0 นาที (ก่อนเปิด) | ______ °C | ______ °C |
| 1 นาที | ______ °C | |
| 2 นาที | ______ °C | |
| 3 นาที | ______ °C | |
| 5 นาที | ______ °C | |
| **นิ่งที่** | **______ °C** | |

**เกณฑ์ตาม §3.5:**

| อุณหภูมิผิวที่นิ่งแล้ว | ผล | ต้องทำอะไรต่อ |
|---|---|---|
| ≤ 60 °C | ✅ ผ่าน | ขับเกตจาก GPIO 3.3 V ตรงได้ ไม่ต้องมี level shifter |
| 60–80 °C | ⚠ ก้ำกึ่ง | ใช้ได้ แต่ควรเพิ่มแผ่นระบายความร้อน และวัดซ้ำตอนอากาศร้อน |
| > 80 °C | 🔴 ไม่ผ่าน | **ต้องกลับมาใส่ level shifter** ตามที่ §3.5 เตือนไว้ |

**คำนวณต่อทันทีหลังกรอก** (สูตรจากไฟล์ 16 §16.4):
```
ΔT = อุณหภูมินิ่ง − อุณหภูมิห้อง = ______ °C
R_DS(on) โดยประมาณ = ΔT / 345.6 = ______ Ω = ______ mΩ
เทียบค่าที่เดาไว้ 60 mΩ → ต่างกัน ______ เท่า
```

> ⚠ ค่า R ที่ได้เป็น**ตัวชี้วัดคร่าวๆ ไม่ใช่การวัด R_DS(on) จริง** เพราะสูตรตั้งอยู่บน R_th = 60 °C/W ซึ่งเองก็เป็นการเดา
> และวัดที่ผิวไม่ใช่ที่จังก์ชัน (จังก์ชันร้อนกว่าเสมอ) → ถือเป็น **ขอบล่าง** · สิ่งที่ตอบได้ตรงๆ คือผ่าน/ไม่ผ่านเกณฑ์อุณหภูมิ

### S5 — หา `SUCTION_DUTY_MIN` *(ทำเฉพาะถ้าจะคุมความเร็วดูดในอนาคต)*

§3.5 เลือกโหมด **เปิด-ปิดอย่างเดียว** ไว้แล้ว เพราะไล่ FSM ทั้ง 12 state แล้วไม่มี state ไหนใช้กำลังดูดระดับกลาง
ขั้นนี้จึงเป็น**ทางเลือก** ทำไว้เผื่ออนาคต

พิมพ์ `pwm on` แล้ว `sweep` · กด Enter ทันทีที่ใบพัดเริ่มออกตัว

> ### 🟠 ก่อนรัน `sweep` ครั้งแรก — มีประเด็นที่เอกสารไม่เคยตอบ
> §3.5 พิสูจน์แค่ว่า **MOSFET** ไม่ร้อนที่ 25 Hz แต่**ไม่เคยพิสูจน์ว่าวงจรขับในตัว blower ทนการสับไฟที่ 25 Hz ได้**
> เหตุผลที่ใช้ตัด 20 kHz ทิ้งคือ "การปลุก-ดับวงจรของมันเอง" ซึ่งเป็นเหตุผลเชิงคุณภาพ ไม่ใช่การคำนวณ
> และเหตุผลนั้นไม่ได้หายไปเพราะลดความถี่
>
> ที่ duty 5 % · 25 Hz → คาบ 40 ms มีไฟแค่ **2 ms** ไม่มีไฟ **38 ms** ต่อรอบ
> วงจรในตัว blower อาจ brown-out และรีเซ็ตราว 25 ครั้ง/วินาที ตลอดช่วง duty ต่ำ
>
> **ถ้ามีออสซิลโลสโคป:** จับที่ขั้ว blower ที่ duty 5–20 % ดูว่าแรงดันตกลงไปแค่ไหน ก่อนไล่ sweep เต็มช่วง
> **ถ้าไม่มี:** เริ่ม sweep ที่ duty สูงขึ้น หรือฟังเสียง/ดูใบพัด ถ้าออกตัวๆ ดับๆ ผิดปกติให้หยุดทันที
> **[ยังไม่ตัดสิน]** — บันทึกไว้เป็นประเด็นเปิด ยังไม่มีใครวัด
>
> **เวลาที่ `sweep` ใช้ถ้าไม่กด Enter เลย:** 20 ขั้น × (2 s ค้าง + 0.4 s พัก) = **48 วินาที** · blower มีไฟรวม 40 วินาที · start/stop 20 ครั้ง

| ความถี่ | `SUCTION_DUTY_MIN` | กระแสที่ duty นั้น | ไฟ CC ของแหล่งจ่ายติดไหม |
|---|---:|---:|---|
| 25 Hz | ______ % | ______ A | ☐ ติด ☐ ไม่ติด |
| 50 Hz | ______ % | ______ A | ☐ ติด ☐ ไม่ติด |

⚠ **ค่าที่ได้เป็นขอบบน ไม่ใช่ค่าจริง** เพราะรวมเวลาปฏิกิริยาของคน (ปกติ 200–400 ms) ตอนจดลงไฟล์ 08 ต้องกำกับป้ายนี้ไว้
⚠ **ถ้าไฟ CC (จำกัดกระแส) ของแหล่งจ่ายติดระหว่าง sweep** แปลว่าการชาร์จคาปาซิเตอร์ของ blower ซ้ำๆ ดันชนขีดจำกัด → **ค่าที่อ่านได้จาก S5 ใช้ไม่ได้** ต้องขึ้น limit แล้วทำใหม่

จบแล้วพิมพ์ `pwm off` เพื่อกลับโหมดปกติ

> **หมายเหตุ:** เฟิร์มแวร์ใช้ **13 บิต** ไม่ใช่ 10 บิตตามที่ §3.5 เขียนไว้ เพราะ **25 Hz ที่ 10 บิตตั้งไม่ได้จริงบน ESP32-S3**
> (ตัวหาร LEDC ได้ 800,000 ซึ่งเกินเพดาน 262,143) รายละเอียดที่ [`08_การคำนวณ/17`](../08_การคำนวณ/17_ข้อจำกัด_LEDC_บน_ESP32-S3.md) · ความขัดแย้งบันทึกไว้ที่ไฟล์ 10 ข้อ **C15**

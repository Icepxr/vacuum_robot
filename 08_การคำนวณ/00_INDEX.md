# 08_การคำนวณ — สมุดคำนวณกลางของโปรเจกต์ MRC-001

รวบรวม **การคำนวณทั้งหมดที่เคยทำในโปรเจกต์นี้** ให้อยู่ที่เดียว พร้อม *วิธีคำนวณ* และ *สมมติฐาน* เพื่อให้ตรวจซ้ำได้เอง
สร้างเมื่อ 3 ก.ย. 2026 · ดึงข้อมูลจากไฟล์ที่มีอยู่จริงในโปรเจกต์ ไม่มีตัวเลขใหม่ที่แต่งขึ้นเอง

---

## กติกาการใช้และดูแลไฟล์ชุดนี้

1. **ทุกครั้งที่มีการคำนวณใหม่ที่เกี่ยวกับโปรเจกต์ ต้องจดลงในไฟล์ชุดนี้** (เพิ่มในไฟล์หัวข้อที่ตรง หรือสร้างไฟล์ใหม่แล้วเพิ่มบรรทัดในตารางด้านล่าง)
2. แต่ละรายการต้องมีครบ 5 อย่าง: **สมมติฐาน → สูตร → แทนค่า (พร้อมหน่วย) → ผลลัพธ์ → ระดับความมั่นใจ**
3. ห้ามแก้ตัวเลขเก่าทับเงียบๆ — ถ้าค่าเปลี่ยน ให้เขียนบรรทัดใหม่พร้อมวันที่และเหตุผลที่เปลี่ยน แล้วขีดฆ่า/ทำเครื่องหมายค่าเดิมว่า superseded
4. ถ้าคำนวณใหม่แล้วขัดกับค่าที่ล็อกไว้ในไฟล์อื่น (BOM, system_architecture.md) → เพิ่มเข้า `10_ประเด็นค้างและความขัดแย้ง.md` ก่อน อย่าตัดสินเองฝ่ายเดียว

## ป้ายระดับความมั่นใจ (ใช้ทุกไฟล์)

| ป้าย | ความหมาย |
|---|---|
| **[วัดจริง]** | มีตัวเลขจากการวัดด้วยเครื่องมือจริงแล้ว |
| **[คำนวณ]** | คำนวณจากสมมติฐานที่ระบุไว้ ยังไม่ได้วัดยืนยัน |
| **[สเปก]** | มาจาก datasheet / สเปกผู้ขาย — ระบุแหล่งไว้ ถ้าไม่ระบุ = ยังไม่ยืนยัน |
| **[ประมาณการ]** | ค่าที่เดาจากประสบการณ์ทั่วไป ยังไม่มีแหล่งอ้างอิง — ความเสี่ยงสูงสุด |
| **[ยังไม่ตัดสินใจ]** | ยังไม่ล็อก |

> ### 🔴 สถานะเร่งด่วน ณ 3 ก.ย. 2026
> **กลไกยก scissor เป็นดีไซน์เก่าที่ยังไม่ได้อัปเดต** (ผู้ใช้ยืนยันเอง) → ไฟล์ 06, 07 และตัวเลขบางส่วนในไฟล์ 08 **ห้ามนำไปใช้ตัดสินใจ**
> สูตรและวิธีคำนวณในไฟล์เหล่านั้นยังใช้ซ้ำได้ เปลี่ยนแค่ค่าที่ป้อนเข้า · ดู `10_ประเด็นค้างและความขัดแย้ง.md` ข้อ S0
>
> **อัปเดต 3 ก.ย. 2026 (รอบบ่าย): มีไฟล์ 12 แล้ว** — คำนวณกลไกยกใหม่ H ≥ 550 mm เซอร์โว 1 ตัว ครบชุด (ยังรอผู้ใช้ยืนยันอินพุต 4 ตัว)
>
> **สถานะรวม ณ 3 ก.ย. 2026: ยังไม่มีรายการไหนเป็น [วัดจริง] เลย** — ไฟล์ `03_ผลการทดสอบ/แบบบันทึกผลการทดลอง_หุ่นดูดฝุ่น.xlsx` ยังเป็นแบบฟอร์มเปล่า ทุกตัวเลขในสมุดชุดนี้จึงเป็น [คำนวณ] / [สเปก] / [ประมาณการ] ทั้งหมด

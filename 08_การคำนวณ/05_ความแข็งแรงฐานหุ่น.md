## 5.2 สูตร

```
หน้าตัดสี่เหลี่ยม:   I = b·t³/12        c = t/2

โมเมนต์สูงสุดของคาน simply supported ที่โหลดจุดกึ่งกลาง:
    M_max = F·L/4

ความเค้น:            σ = M·c / I
แรงสูงสุดก่อนคราก:   F_max = σ_allow · I / (c · L/4) = σ_allow · b · t² / (1.5 L)
การแอ่นตัวกึ่งกลาง:  δ = F·L³ / (48·E·I)
Safety factor:       FoS = σ_allow / σ(F_service)
```

**ตรวจสอบด้วยมือ (PLA t = 3 mm):**
```
I = 0.080 × 0.003³ / 12 = 1.80e-10 m⁴
F_max = 40e6 × 0.080 × 0.003² / (1.5 × 0.180) = 28.8 / 0.27 = 106.7 N   ✓ (ตาราง 107)
σ(8.83 N) = (8.83 × 0.180/4) × 0.0015 / 1.80e-10 = 3.31 MPa
FoS = 40 / 3.31 = 12.1   ✓
δ = 8.83 × 0.180³ / (48 × 3.5e9 × 1.80e-10) = 0.0515 / 30.24 = 1.70 mm   ✓
```

## 5.4 ข้อสรุปเชิงวิศวกรรม

1. **การหัก/คราก ไม่ใช่ตัวชี้ขาด** — ตั้งแต่หนา 3 mm ขึ้นไป FoS > 9 แม้เผื่อ impact 2× แล้ว
2. **ตัวชี้ขาดคือการแอ่นตัว (deflection)** — PETG 2 mm แอ่นได้ ~9.6 mm ซึ่งจะทำให้ฐานงอ กระทบตำแหน่งเซนเซอร์กันตกและแรงกดหัวดูด
   → **เกณฑ์ที่ควรใช้: แอ่น < ~1 mm** ไม่ใช่ FoS
3. **คำแนะนำ:** PLA หรือ PETG **หนา 3–4 mm + infill 30–40%**
   - จุดที่รับมอเตอร์ดูด/แบต/scissor ให้เติม **ครีบเสริม (ribs)** หรือ boss หนาแทนการเพิ่มความหนาทั้งแผ่น (เบากว่าที่ความแข็งเท่ากัน — เพราะ I ∝ t³ แต่มวล ∝ t)
   - ถ้ากลัวตกกระแทก เลือก **PETG** (เหนียว ไม่เปราะแตกเหมือน PLA)

> **โหลดจาก scissor lift ไม่ได้อยู่ในตารางนี้** — แรงแนวนอน 87 N จาก slider เป็น**แรงภายในของแผ่นฐาน scissor เอง** (ดูไฟล์ 07 §7.1) ไม่ส่งลงฐานหุ่น **ตราบใดที่จุดหมุนและรางเลื่อนอยู่บนแผ่นเดียวกัน**

## 5.5 ขั้นตอนรัน Static Stress ใน Fusion 360 (งานที่ยังค้าง)

1. เปิด `Base1.1.f3d` → สลับ workspace เป็น **Simulation**
2. Study type: **Static Stress**
3. Material — ถ้าไม่มีในไลบรารีให้ Add:
   - PLA: E **3500 MPa**, Poisson 0.36, Yield 50 MPa, Density 1.24 g/cc
   - PETG: E **2100 MPa**, Poisson 0.40, Yield 50 MPa, Density 1.27 g/cc
4. Constraints (Fixed): รูยึดล้อขับซ้าย-ขวา + ล้อประคองหน้า
5. Loads: เปิด Gravity · Remote Force ที่จุดวางของหนัก (แบต 4.4 N, มอเตอร์ดูด 1.5 N, scissor 2.0 N) · ถ้าจะทดสอบเหยียบ ใส่ 50 N หรือ 100 N กลางฐาน
6. Mesh ค่าเริ่มต้นก่อน แล้วค่อย refine
7. อ่านผล: **Safety Factor ≥ 2 ทั้งชิ้น** · Von Mises เทียบ Yield · **Displacement < 1 mm**

> **วิธีตีความ:** ถ้า Fusion ให้ FoS ใกล้ตารางข้างบน (สิบกว่าๆ ที่ 3–4 mm) = โมเดลสอดคล้อง
> ถ้าต่างมาก มักเป็นเพราะ constraint/geometry จริงต่างจากสมมติฐานคาน → **ให้เชื่อค่า Fusion**

## 5.6 คำนวณใหม่หลังเปลี่ยนแบต (4 ก.ย. 2026)

**เหตุ:** ชิ้นที่กดจุดเดียวหนักที่สุดคือ**แบต** ซึ่งเปลี่ยนจาก 0.450 → **0.231 kg** (LiPo GNB `GNB22004S100A`)

```
F_service = m_แบต × g × impact factor 2
เดิม: 0.450 × 9.81 × 2 = 8.83 N
ใหม่: 0.231 × 9.81 × 2 = 4.53 N        →  อัตราส่วน 0.513
σ ∝ F  และ  การแอ่นตัว ∝ F   (เชิงเส้นทั้งคู่ในช่วงยืดหยุ่น)
```

| | เดิม (แบต 0.45 kg) | **ใหม่ (แบต 0.231 kg)** |
|---|---:|---:|
| F_service | 8.83 N | **4.53 N** |
| σ ที่จุดกด (ตัวอย่าง §5.3) | 3.31 MPa | **1.70 MPa** |
| **FoS (PLA σ_allow 40 MPa)** | 12.1 | **23.5** |
| การแอ่นตัว | ค่าเดิม × 1.00 | **× 0.513** |

**ตรวจสอบ:** 3.31 × 0.5133 = 1.699 MPa · 40 / 1.699 = 23.5 ✓

**ผล: ฐานปลอดภัยขึ้นเกือบเท่าตัว และ "แอ่น < 1 mm" ซึ่งเป็นเกณฑ์ชี้ขาดตาม §5.4 ก็ผ่านง่ายขึ้น** — **[คำนวณ]**

**สิ่งที่ยังไม่แก้และต้องทำ:**
- `base_strength_analysis.py` ยังฮาร์ดโค้ด M = 2.47 kg และแบต 0.45 kg → ถ้ารันใหม่ต้องแก้เป็น **M = 2.342 kg · แบต 0.231 kg** (และแก้ path เอาต์พุตตาม W8)
- ขั้นตอน Fusion 360 §5.5 ข้อ 5: **Remote Force ของแบตเปลี่ยนจาก 4.4 N → 2.27 N**
- มวลรวมที่ใช้ในรายงานนี้ (2.47 kg) ยังขัดกับค่าที่ควรเป็น — ดูไฟล์ 10 ข้อ C3 ที่อัปเดตแล้ว

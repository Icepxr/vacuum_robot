## 6.2 เรขาคณิต scissor — ทำไม 7 ชั้น × 80 mm

**สูตรพื้นฐาน:**
```
ความสูงยก:            H    = n · L · sin θ
ความยาวแนวนอนที่กิน:  span = L · cos θ
```

**ตรวจ 2 ทางเลือกกับข้อจำกัด "ฐาน 100 mm":**

| ทางเลือก | span ตอนพับ | + ครีบหมุด 8 + แคร่ 8 | รัศมี crank ที่ต้องใช้ | ผล |
|---|---|---|---|---|
| 6 ชั้น × 85 mm | 83.7 mm | 99.7 mm | 33.6 mm → ร่อง yoke กว้าง 87 mm | ✗ กินฐานหมด + ร่องชนขอบ |
| **7 ชั้น × 80 mm** | **79.2 mm** | **95.2 mm** | **19.0 mm** → ร่อง 53 mm | ✓ เหลือขอบ 4.8 mm |

**มุมที่เลือก:**
```
θ_min = 8.0°   → H = 7 × 80 × sin 8°    = 560 × 0.13917 = 77.9 mm
θ_max = 58.8°  → H = 7 × 80 × sin 58.8° = 560 × 0.85507 = 478.9 mm
```
**ความสูงรวมของโมดูล** = Z_PIN(11) + 479.0 + ช่องว่างใต้แพลตฟอร์ม(6) + หนาแพลตฟอร์ม(3) = **499.0 mm** ✓

### ข้อจำกัดความกว้างแขน — ตัวเลขที่ CAD จับได้

ตอนพับสุด แขน**ชั้นเดียวกัน**ของชั้นติดกันจะขนานกันและห่างกันแค่:
```
d = L · sin θ_min · cos θ_min = 80 × 0.13917 × 0.99027 = 11.02 mm
```
→ ถ้า LINK_W > 11.02 mm **แขนชนกันตอนพับ** (ค่าเดิม 14 mm ชนแน่นอน)
→ **LINK_W = 10.0 mm** (เหลือช่อง 1.02 mm) · หนา LINK_T = 3.2 mm

## 6.3 กลไกขับ — ทำไม SCOTCH YOKE ไม่ใช่ crank + ก้านต่อ

**เหตุผลที่ 1 — พื้นที่:**
```
crank + ก้านต่อ กินความยาว (r + l) ≈ 114 mm > ฐาน 100 mm  ✗ ใส่ไม่ลง
scotch yoke ไม่มีก้านต่อ กินแค่ 2r = 38.0 mm               ✓
```

**เหตุผลที่ 2 — จุดศูนย์ตาย (นี่คือหัวใจของดีไซน์):**
```
x_slider(φ) = x_c + r · cos φ
dx/dφ       = −r · sin φ        →  ที่ φ = 0° และ 180°  dx/dφ = 0
```
scissor ต้องการแรงมากที่สุดตอนพับ (`F ∝ cot θ` พุ่งขึ้น) แต่ scotch yoke ให้ `dx/dφ ≈ 0` ตรงจุดนั้นพอดี → **สองเส้นโค้งหักล้างกัน** เซอร์โวได้เปรียบเชิงกลมหาศาล

**ผลพลอยได้ที่สำคัญต่อระบบไฟ:** ตอนพับสุดกลไก **ล็อกตัวเอง** — โหลดกดลงมาก็หมุน crank กลับไม่ได้ → **ตัด PWM ทิ้งได้เลยตอนเก็บ** ไม่กินไฟ ไม่ร้อน ไม่สั่น

### การคำนวณ crank

```
ระยะชัก slider = L(cos θ_min − cos θ_max) = 80(0.99027 − 0.51825) = 37.78 mm
                 (slider เดินจาก x = 79.2 → 41.4 mm)

เลือกเยื้องจากจุดศูนย์ตายตอนพับสุด  φ₀ = 9°

r_crank = stroke / (1 + cos φ₀) = 37.78 / (1 + 0.98769) = 37.78 / 1.98769 = 19.01 mm
x_c     = 79.22 − 19.01 × cos 9° = 60.45 mm  จากจุดหมุนตายตัว
```

| รายการ | ค่า |
|---|---|
| รัศมี crank r | **19.01 mm** |
| ศูนย์กลาง crank x_c | 60.45 mm |
| ขอบเขตที่ crank กวาดแกน X | 41.4 … 79.5 mm |
| ขอบเขตแกน Y (ร่อง yoke) | ±19.0 mm (ฐาน ±50 mm ✓) |
| ช่วงหมุนเซอร์โว | φ = 9° → 180° = **171°** (MG996R มี 180° ✓) |

## 6.4 แรง actuator จากงานเสมือน (virtual work)

**สมมติฐานมวล (ประเมินจากเรขาคณิต CAD — [คำนวณ]):**

| ส่วน | จำนวน | มวล |
|---|---|---|
| แขน scissor | 28 ชิ้น × 3.56 g | 99.7 g |
| แกนขวางอะลูมิเนียม | 6 ชิ้น × 1.56 g | 9.4 g |
| สกรู/สเปเซอร์ | | 44.8 g |
| slider block | | 12.0 g |
| **m_scissor (กระจายตัว, CoG ที่ H/2)** | | **166 g** |
| แพลตฟอร์มบน | | 35.0 g |
| payload (กล้อง) | | 60.0 g |
| **m_top (ที่ปลายบน, CoG ที่ H)** | | **95 g** |

**น้ำหนักสมมูล:**
```
W_eff = (m_top + m_scissor/2) · g = (0.095 + 0.0830) × 9.81 = 1.75 N
```
*(m_scissor หาร 2 เพราะ CoG อยู่ที่ H/2 → พลังงานศักย์ได้ครึ่งเดียวเมื่อยกสูง H)*

**อนุพันธ์งานเสมือน:**
```
U_grav = (W_top + W_scissor/2) · n · L · sin θ
x_s    = L · cos θ
F_act  = |dU/dθ| / |dx_s/dθ| = n · W_eff · cot θ        [ยังไม่คิดความฝืด]
```

**แทนค่า:**
```
θ = 8°  (เริ่มยก):  F = 7 × 1.75 × cot 8°  = 12.25 × 7.115 = 86.9 N  ← พีค
θ = 59° (ยกสุด):   F = 7 × 1.75 × cot 58.8° = 12.25 × 0.606 =  7.4 N
```

**อัตราขยายแรงที่ θ = 8°:** `n · cot θ = 7 × 7.115 = 49.8 เท่า`
→ นี่คือ**ราคาที่ต้องจ่าย**ของ "พับ 78 mm แต่ยืด 479 mm" (อัตราขยายระยะ 6.1:1)

## 6.5 สปริงช่วย — ทำไมต้องยึดทแยง ไม่ใช่ตามราง

**ปัญหาของสปริงเชิงเส้นตามราง:** ช่วยไม่ตรงกับเส้นโค้ง `cot θ` → **ช่วงกลางช่วยเกินพอดี** แล้ว scissor จะ **เด้งขึ้นเองตอนไฟดับ** = อันตราย

**วิธีแก้:** ยึดทแยงจากฐาน → จุด `p·L` บนแขนล่าง เส้นโค้งแรงจะโค้งตาม `cot θ` ได้ดีกว่ามาก

**แบบจำลอง:**
```
จุดบนแขน:   (px, py) = (p·L·cos θ, p·L·sin θ)
ความยาวสปริง s = |(px,py) − (xa,ya)|
ds/dθ = [(px−xa)·dpx/dθ + (py−ya)·dpy/dθ] / s
dU_spring/dθ = k · max(s − s₀, 0) · ds/dθ

F_act = (dU_grav/dθ + dU_spring/dθ) / (L · sin θ)
```

**การค้นหาพารามิเตอร์ (grid search) — เกณฑ์ optimize คือ "แรงบิดเซอร์โวพีค" ไม่ใช่ "แรงพีค"** เพราะ crank แปลงค่าไม่เชิงเส้น

**เงื่อนไขบังคับ 3 ข้อในการค้นหา:**
1. `F_act > 0.25 N ตลอดช่วง` — กันกลไกยกตัวเอง (self-deploy)
2. `ยืดสูงสุด ≤ 80% ของความยาวอิสระ` — ข้อจำกัดสปริงดึงจริง
3. `s₀ ≤ s_min` — ต้องตึงตลอด ไม่หย่อนกลางทาง
4. ข้อจำกัดการจัดวาง: `xa ∈ [0, 40] mm`, `ya ∈ [0, 25] mm` (ค่าติดลบทำให้ตายึดยื่นพ้นขอบฐาน — CAD จับได้)

**ผลค้นหา (ค่า optimum):**

| พารามิเตอร์ | ค่า |
|---|---|
| จุดยึดบนฐาน A | (0, 10) mm เทียบจุดหมุนตายตัว |
| จุดยึดบนแขนล่าง | 0.90·L = 72.0 mm จากจุดหมุน |
| k (optimum) | 3.00 N/mm |
| ความยาวอิสระ s₀ | 40 mm |
| ความยาวใช้งาน | 64 → 71 mm (ยืดสูงสุด 31 mm) |

**แรง actuator พีค: 86.9 N → 2.6 N (ลด 97%)**

### ⚠ ตรวจความทนทานต่อ tolerance ของสปริง — จุดที่บังคับให้ต้อง de-rate

| k คลาดเคลื่อน | F_act ต่ำสุด…สูงสุด | T พีค | ผล |
|---|---|---|---|
| ×0.80 | 2.54 … 19.47 N | 2.77 kgf·cm | OK |
| ×0.90 | 1.93 … 11.04 N | 2.25 kgf·cm | OK |
| ×1.00 | 1.32 … 2.60 N | 1.79 kgf·cm | OK |
| **×1.10** | **−5.83** … 0.75 N | 1.38 kgf·cm | ✗ **ติดลบ = กลไกดันตัวขึ้นเอง** |
| ×1.20 | −14.26 … 0.11 N | 1.03 kgf·cm | ✗ อันตราย |

**สปริงจริงมี tolerance ~±10%** → ถ้าเลือกที่ค่า optimum พอดี มีโอกาสได้สปริงแข็งเกินแล้วกลไกยกตัวเอง

### จุดออกแบบที่ใช้จริง — de-rate k ลง 15%

```
k_รวม = 3.00 × 0.85 = 2.55 N/mm  →  สปริง 2 ตัว ตัวละ 1.27 N/mm
ยาวอิสระ 40 mm · ยืดใช้งานสูงสุด 31 mm · แรงต่อตัวสูงสุด 39.9 N
F_act เหลือ 2.23 … 15.25 N   (บวกตลอด = ไม่ยกตัวเอง ✓)
```

> **สปริงที่ต้องซื้อ:** สปริงดึง 2 ตัว **k = 1.27 N/mm** ยาวอิสระ 40 mm ยืดได้ ≥ 35 mm รับแรง ≥ 45 N · ยึดข้างละระนาบเพื่อไม่ให้เกิดโมเมนต์บิด
> **ต้องวัด k ของสปริงจริงก่อนติดตั้ง:** แขวนน้ำหนักที่รู้ค่า (ขวดน้ำ 500 g = 4.9 N) แล้ววัดระยะยืด → `k = F(N) / ระยะยืด(mm)`
> **ถ้าหาค่าตรงไม่ได้ ให้เลือกค่าต่ำกว่าไว้ก่อน** — แค่ทำให้เซอร์โวทำงานหนักขึ้น (SF ยังเหลือ 4.4) แต่ค่าสูงเกินคือความเสี่ยงด้านความปลอดภัย

## 6.6 แรงบิดเซอร์โว MG996R

**สมมติฐาน:**
```
η_joint = 0.65   (ความฝืดหมุด 12+ จุด)   [ประมาณการ]
η_crank = 0.90   (crank-slider)          [ประมาณการ]
η_รวม   = 0.65 × 0.90 = 0.585
F_stiction = 6.0 N ที่ slider (ค่าคงที่ ไม่ขึ้นกับโหลด)  [ประมาณการ]
```

> ***จุดที่สำคัญที่สุดของการวิเคราะห์นี้:*** เมื่อใส่สปริงจนเกือบสมดุลแล้ว **"ความฝืด" กลายเป็นภาระหลักแทน "น้ำหนัก"** ถ้าไม่ใส่พจน์ stiction จะประเมินดีเกินจริงมาก

**สูตร:**
```
T_servo(φ) = (F_act/η + F_stiction) · |dx_s/dφ|
           โดย |dx_s/dφ| = r · |sin φ|   [หน่วย m/rad]
```

**ผลลัพธ์:**

| กรณี | T พีค | เกิดที่ | SF (เทียบ 11 kgf·cm) | ตัดสิน |
|---|---|---|---|---|
| ไม่มีสปริง | 0.762 N·m = **7.8 kgf·cm** | φ=39°, θ=20°, H=189 mm | **1.42** | ⚠ เฉียดฉิว |
| **มีสปริง + คิดความฝืด** | 0.245 N·m = **2.5 kgf·cm** | φ=70°, θ=33°, H=308 mm | **4.40** | ✓ ผ่าน (เป้า ≥2.0) |

```
ตรวจสอบ: SF = 11.0 kgf·cm × 0.0980665 / 0.2453 N·m = 1.0787 / 0.2453 = 4.40  ✓
```

> ⚠ **สเปก 11 kgf·cm ของ MG996R เป็นค่าที่ 6 V** แต่ระบบไฟล็อกไว้ที่ราง **5 V**
> ที่ 5 V แรงบิดเหลือ ~9.4–9.7 kgf·cm → **SF ลดเหลือ ~3.8–3.9** ยังผ่านเกณฑ์ ≥2.0 สบาย
> (ตัวเลข 9.4 กับ 9.67 ปรากฏขัดกันเองใน `system_architecture.md` — ดูไฟล์ 10 ข้อ C5)

## 6.7 ไฟฟ้าของเซอร์โว

```
เวลายกที่ตั้งไว้ = 3.0 s
ความเร็วเซอร์โวที่ต้องการ = 171° / 3 s = 57 °/s     (MG996R ทำได้ ~330 °/s ✓ เดินช้าได้สบาย)

กระแสพีคประมาณ = I_stall × min(1, T_พีค/T_สเปก × 1.6)
               = 2.5 × (0.2453/1.0787 × 1.6) = 2.5 × 0.364 = 0.91 A  ที่ 6 V
พลังงานต่อรอบยก ≈ 0.91 A × 6 V × 3 s = 16 J
```
> ตัวคูณ **1.6** ในสูตรกระแสเป็น **[ประมาณการ]** ที่ไม่มีที่มาระบุไว้ — ควรวัดกระแสจริงที่ทดสอบ 1.4 แทนการเชื่อค่านี้

**ข้อกำหนดไฟที่ตามมา:**
1. เซอร์โวต้องอยู่**คนละรางกับลอจิก** (Pi 5 / ESP32) — ดูไฟล์ 02 §2.7
2. คาปา **1000 µF ที่ขั้วไฟเซอร์โว** (ไม่ใช่ที่ buck)
3. star ground จุดเดียว
4. **detach PWM เมื่อถึงตำแหน่ง** — ตอนพับสุด crank ล็อกตัวเองอยู่แล้ว · ตอนยกสุด crank อยู่ใกล้จุดศูนย์ตายอีกด้าน กินกระแสน้อย

## 6.8 ⚠ กรณีเซอร์โว 2 ตัว (การตัดสินใจใหม่ใน rev.6) — ยังไม่ได้คำนวณซ้ำ

`system_architecture.md` rev.6 เปลี่ยนเป็น **MG996R 2 ตัวขนานกันบน scissor ตัวเดียว** แต่ไฟล์ในโฟลเดอร์ `06_Scissor_Lift/` ทั้งหมด **ยังคำนวณบนสมมติฐานเซอร์โว 1 ตัว**

**สิ่งที่ rev.6 ตรวจแล้ว:** ผลต่อ CoG/การพลิก (ดีขึ้นเล็กน้อย เพราะเซอร์โวอยู่ใต้ดาดฟ้า ต่ำกว่า CoG เดิม) — ดูไฟล์ 08

**ความเสี่ยงใหม่ที่ตัวเลขเดิมไม่ครอบคลุม:** MG996R เป็นเซอร์โว **open-loop มี dead-band ±2–3°** ถ้ายึดแข็งเข้ากลไกเดียวกัน ตัวหนึ่งจะดันสวนอีกตัวตลอดเวลา → **กินกระแส stall ต่อเนื่อง ร้อน และไหม้ แม้หุ่นหยุดนิ่ง**
ที่แย่กว่าปกติ: กลไกนี้**ล็อกตัวเองเฉพาะตอนพับสุด** ตอนยกสุดต้องคาไฟไว้ — ซึ่งเป็นจังหวะที่เสี่ยงที่สุดพอดี

**มาตรการ 3 ข้อ เรียงตามความจำเป็น:**

| ลำดับ | มาตรการ | ต้นทุน | หมายเหตุ |
|---|---|---|---|
| 1 | **ยึดเซอร์โวตัวที่ 2 แบบมีระยะเผื่อ** (รูสลอต / บูชยาง) ให้ horn รับความต่าง dead-band ได้โดยไม่ส่งแรงเข้ากลไก | 0 บาท | **นี่คือทางแก้จริง** อีก 2 ข้อเป็นแค่การเฝ้าระวัง |
| 2 | G12 — จำกัดเวลาที่เสาอยู่ตำแหน่งยก ≤ 15 s แล้วพับอัตโนมัติ | 0 บาท | จำกัดเวลาเสี่ยง ไม่ได้แก้ต้นเหตุ |
| 3 | ACS712-5A บนรางเซอร์โว + G13 (>1.5 A ค้าง 2 s → ตัด PWM + FAULT) | ~40 บาท | ทางเดียวที่ซอฟต์แวร์จะรู้ว่ากำลังสู้กัน ไม่มี = ตาบอด |

> **คำถามที่ควรตอบก่อน:** SF ของเซอร์โวตัวเดียวคือ **4.4** อยู่แล้ว (ใช้จริง 2.5 จาก 11 kgf·cm) → **แรงบิดไม่ใช่ปัญหา**
> ถ้าเหตุผลที่ใส่ตัวที่ 2 คือ "กลัวแรงไม่พอ" ตัวเลขบอกว่าไม่จำเป็น และการใส่เพิ่ม**สร้างความเสี่ยงใหม่ที่ไม่มีมาก่อน**
> ถ้าเหตุผลคือ **กันเสาบิด/แกว่งด้านข้าง** (ความเสี่ยงอันดับ 1 ในไฟล์ 07 — ±9.3 mm) นั่นเป็นเหตุผลที่ถูกต้อง เพราะขับสองข้างสมมาตรลดการบิดได้จริง → ทำมาตรการที่ 1 ให้ดีแล้วเดินหน้าต่อ

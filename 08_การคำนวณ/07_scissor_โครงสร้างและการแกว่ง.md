## 7.1 แรงที่ฐาน — ทำไมหุ่นไม่ถูกผลัก (ประเด็นที่ถามบ่อยที่สุด)

**แรงแนวนอนสูงสุดที่ slider = 86.9 N** (คิดกรณีเลวสุด: สปริงขาด/ไม่ได้ใส่)

87 N ฟังดูเยอะมาก แต่เป็น **แรงภายใน (internal force)** เพราะ**ทั้งจุดหมุนตายตัวและรางเลื่อนยึดอยู่บนแผ่นฐานเดียวกัน**
→ ผลรวมแรงที่ส่งลงตัวหุ่นในแนวนอน = **0** หุ่นจะไม่ถูกผลักตอนสั่งยก

> ⚠ **เงื่อนไขบังคับ:** ห้ามยึดรางเลื่อนกับโครงหุ่นคนละชิ้นกับจุดหมุนเด็ดขาด
> **ถ้าแยกเป็นสองชิ้น แรง 87 N จะกลายเป็นแรงจริงที่ผลักโครงหุ่นทันที** — นี่คือข้อผิดพลาดที่ทำได้ง่ายมากตอนประกอบ

**ความเค้นดึงในแผ่นฐาน scissor:**
```
A = BASE_Y × BASE_T = 100 × 5 = 500 mm²
σ = 86.9 N / 500 mm² = 0.174 MPa   (ยอมให้ 15 MPa)  → SF 86  ✓ เหลือเฟือ
```

---

## 7.2 ความเค้นในแขนและหมุด

**แรงอัดตามแนวแขนล่าง (แบ่ง 2 แขน × 2 ระนาบ):**
```
F_link = F_slider / cos θ_min / 2 / 2 = 86.9 / 0.99027 / 4 = 21.9 N ต่อแขน
A_link = 10.0 × 3.2 = 32 mm²
σ = 21.9 / 32 = 0.69 MPa   (ยอมให้ 15 MPa)  ✓
```

**การโก่งเดาะ (Euler, pinned-pinned, แกนอ่อน = นอกระนาบ):**
```
I = b·t³/12 = 10 × 3.2³ / 12 = 27.31 mm⁴
P_cr = π²·E·I / L² = 9.8696 × 2000 × 27.31 / 80²
     = 539,077 / 6,400 = 84.2 N
SF = 84.2 / 21.9 = 3.8   ✓  (เกณฑ์ >3)
```

**ความเค้นเฉือนที่หมุด M3:**
```
A_pin = π × 1.5² = 7.07 mm²
τ = 21.9 / 7.07 = 3.1 MPa    (สกรูเหล็กเกรด 4.8 รับได้ ~200 MPa)  → SF 64  ✓
```

**สรุป §7.1–7.2: ความแข็งแรงเชิงวัสดุ ไม่ใช่ปัญหาของดีไซน์นี้เลย** ทุกจุด SF > 3.8

> **สิ่งที่ยังไม่ได้ตรวจ: bearing stress ที่รูหมุด** (ความเค้นสัมผัสระหว่างสกรูกับเนื้อพลาสติกรอบรู) — เป็นจุดที่ชิ้นพิมพ์ 3D มักพังจริง โดยเฉพาะหลังลดความกว้างแขนจาก 14 → 10 mm · แนะนำให้รัน FEA ที่มุมพับสุด (จุดที่แรงในแขนสูงสุด)

## 7.3 ⭐ ปัญหาจริงคือการแกว่ง ไม่ใช่ความแข็งแรง

### ความแข็งด้านข้างของวัสดุ (ขอบบนสุด — คิดเป็นเสาตัน)

สองระนาบทำตัวเป็น "เสากล่อง":
```
I_tower = 2 × (LINK_W × LINK_T) × (TRACK_Y/2)²
        = 2 × 32 mm² × 31² mm² = 61,504 mm⁴

H_up = 478.9 mm
k_beam = 3·E·I / H³ = 3 × 2000 × 61,504 / 478.9³
       = 369.0e6 / 1.0982e8 = 3.36 N/mm

แรงข้าง 1 N → โก่ง 1/3.36 = 0.30 mm
```
**ถ้าคิดแค่วัสดุ เสานี้แข็งมาก** — แต่นั่นไม่ใช่สิ่งที่จะเกิดจริง

### ⚠ ความหลวมของหมุด — ตัวเลขที่ครอบงำทุกอย่าง

**สมมติฐาน:** ความหลวมรวมต่อหมุดหนึ่งจุด **clr = 0.15 mm** (รู 3.2 mm กับสกรู 3.0 mm + สึกหรอ) — **[ประมาณการ]**

```
มุมเอียงที่แต่ละชั้นทำได้อิสระ:
tilt_ต่อชั้น = 2 × clr / TRACK_Y = 2 × 0.15 / 62 = 0.004839 rad

ความเอียงของชั้นล่างถูกขยายด้วยความสูงที่เหลือเหนือมันขึ้นไป:
wander = Σ [ tilt_ต่อชั้น × (H_up − z_k + H_up/n) ]   สำหรับ k = 1..7
       = 0.004839 × 1,915.7 mm
       = 9.27 mm
```

**ผล: ปลายเสาแกว่งอิสระ ≈ ±9.3 mm (1.11° ที่ปลาย)** — **[คำนวณ]**

> **นี่คือ "ระยะหลวม" ที่ไม่มีแรงต้านเลย ไม่ใช่การโก่งของวัสดุ** — เทียบกัน: แรง 1 N ทำให้โก่งจากวัสดุแค่ 0.30 mm แต่ความหลวมให้ 9.3 mm ฟรีๆ โดยไม่ต้องมีแรงเลย
> **ตัวเลขนี้ครอบงำคุณภาพภาพจากกล้อง มากกว่าความแข็งแรงเชิงวัสดุหลายสิบเท่า → เป็นความเสี่ยงอันดับ 1 ของทั้งโมดูล**

### ความถี่ธรรมชาติ

```
k_eff = k_beam × 0.15 = 0.504 N/mm    (ประเมินอย่างระมัดระวัง: ข้อต่อ+ความหลวมลดความแข็งลง ~85%)  [ประมาณการ]
f_n = (1/2π) · √(k_eff / m_top) = (1/6.283) × √(504 N/m / 0.095 kg)
    = (1/6.283) × 72.8 = 11.6 Hz ≈ 12 Hz
```

**ผลต่อการใช้งาน:**
```
เวลาที่ต้องรอให้นิ่ง ≈ 5 คาบ = 5 / 12 Hz = 0.42 s
```
→ ในทางปฏิบัติให้ **ถ่ายภาพ/สแกนเมื่อหุ่นหยุดนิ่งแล้วอย่างน้อย 1–2 วินาที** (เผื่อมากกว่าค่าคำนวณ 3–5 เท่า)

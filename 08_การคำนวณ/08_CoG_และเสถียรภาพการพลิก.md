# 08 — จุดศูนย์ถ่วง (CoG) และเสถียรภาพการพลิกคว่ำ

**ที่มา:** `04_การวิเคราะห์โครงสร้าง/sim_CoG_scissor.ipynb` + `06_Scissor_Lift/scissor_analysis.py` §F + `system_architecture.md` §6.4
**สถานะ:** **[คำนวณ]** · ⚠ ตัวเลขความสูง CoG ตอนยกสุดขึ้นกับกลไก scissor ซึ่ง **ผู้ใช้แจ้งว่าเป็นดีไซน์เก่าที่ยังไม่อัปเดต** — ค่าในหัวข้อ 8.3–8.5 จึงต้องคำนวณใหม่เมื่อกลไกใหม่นิ่งแล้ว

## 8.1 สูตร

```
จุดศูนย์ถ่วง (ค่าเฉลี่ยถ่วงน้ำหนักด้วยมวล):
    r_CoG = Σ(mᵢ · rᵢ) / Σmᵢ
    แยกแกน:  x_CoG = Σmᵢxᵢ/Σmᵢ ,  y_CoG = Σmᵢyᵢ/Σmᵢ ,  z_CoG = Σmᵢzᵢ/Σmᵢ

ระบบแกน: x = หน้า(+)/หลัง(−) · y = ซ้าย/ขวา · z = สูงจากพื้น
วัดทุกชิ้นเทียบจุดอ้างอิงเดียวกัน (จุดกึ่งกลางเพลาล้อบนพื้น)

เสถียรภาพ:
    d_min   = ระยะจาก CoG ถึงขอบฐานรองรับที่ใกล้ที่สุด
    θ_tip   = arctan(d_min / z_CoG)          มุมเอียงวิกฤต
    a_tip   = g · d_min / z_CoG              ความเร่งแนวนอนที่ทำให้เริ่มพลิก
```

**ฐานรองรับ (support polygon) ที่ใช้:** หน้า 0.110 · หลัง 0.110 · ซ้าย 0.100 · ขวา 0.100 m

## 8.3 ผลลัพธ์ (บนกลไก scissor **แบบเดิม** — ต้องคำนวณใหม่)

| | พับเก็บ (H = 78 mm) | ยกสุด (H = 479 mm) |
|---|---:|---:|
| มวลรวม M | 2.56 kg | 2.56 kg |
| **CoG สูงจากพื้น z** | **52 mm** | **79 mm** |
| ระยะถึงขอบฐานเสี่ยงสุด d | 99 mm | 99 mm |
| มุมเอียงวิกฤต θ_tip | 62.5° | **51.2°** |
| **ความเร่งวิกฤต a_tip** | **18.81 m/s² (1.92 g)** | **12.21 m/s² (1.25 g)** |

**ตรวจสอบ (ยกสุด):**
```
a_tip = 9.81 × 0.099 / 0.0795 = 12.2 m/s²    ✓
θ_tip = arctan(99/79.5) = 51.2°              ✓
```

**สรุปการเปลี่ยนแปลง:** ยกเสาขึ้นทำให้ CoG สูงขึ้นแค่ **27–28 mm** (52 → 79 mm) และความเร่งที่ทำให้พลิกลดลง **35%**

## 8.4 ข้อสรุปที่สำคัญที่สุด — การพลิกคว่ำไม่ใช่ปัญหา

```
หุ่นหนัก 2.56 kg แต่ของที่ยกหนักแค่ 95 g  (3.7% ของมวลรวม)
→ ยกสุดยังต้องเร่งถึง 12.2 m/s² จึงจะพลิก
→ หุ่นดูดฝุ่นเร่งได้จริงราว 0.5 m/s²  →  ห่างจากขีดพลิก 24 เท่า
```

**ปัญหาจริงคือการแกว่งของเสา ไม่ใช่การพลิก** (ดูไฟล์ 07 §7.3)

## 8.5 ที่มาของขีดจำกัดความเร่ง 4.9 m/s² (Guard G3)

```
a_limit = a_tip × 0.40 = 12.34 × 0.40 = 4.94 m/s²  →  ตั้งไว้ที่ 4.9 m/s²
```
**เท่ากับ safety factor 2.5 บนขีดพลิก**

> หมายเหตุ: `scissor_analysis_report.txt` ให้ a_tip สองค่าที่ต่างกันเล็กน้อยในรายงานเดียวกัน — 12.21 m/s² (ใช้ d_min = 99 mm ซึ่งคิดการเยื้องของ CoG ในแกน x) และ 12.34 m/s² (ใช้ d = 100 mm) · G3 คำนวณจากค่าหลัง · ต่างกัน 1% ไม่กระทบข้อสรุป

### กรณีเซอร์โว 2 ตัว (rev.6) — ตรวจแล้ว ไม่ต้องแก้ G3

เพราะเซอร์โวตัวที่ 2 อยู่**ใต้ดาดฟ้าหุ่น** (ต่ำกว่า CoG เดิม) การเพิ่มมวลจึงช่วยให้เสถียรขึ้นเล็กน้อย:

| | เซอร์โว 1 ตัว | เซอร์โว 2 ตัว |
|---|---:|---:|
| CoG ตอนยกสุด | 79.0 mm | **77.9 mm** (ต่ำลง) |
| a_tip | 12.2 m/s² | **12.38 m/s²** (+1.5%) |
| ขีดจำกัด clamp (SF 2.5) | 4.88 m/s² | 4.95 m/s² |

→ **G3 คงค่า 4.9 m/s² ตามเดิม**

## 8.6 โมเมนต์ที่ฐาน scissor ตอนหุ่นเร่ง

```
สมมติ a_drive = 0.5 m/s² (ความเร่งขับปกติ)
M_dyn = (m_top + m_scissor/2) × a × H
      = (0.095 + 0.083) kg × 0.5 m/s² × 0.4789 m
      = 0.0426 N·m

แรงดึงต่อสกรูยึดฐาน (4 ตัว ห่าง 100 mm):
F = M / ระยะ / 2 = 0.0426 / 0.100 / 2 = 0.21 N     → M3 รับได้สบาย ✓
```

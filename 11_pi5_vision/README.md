# 11_pi5_vision — โค้ดฝั่ง Raspberry Pi 5 (กล้อง + OCR มิเตอร์)

> โฟลเดอร์เปล่า สร้างไว้รอโค้ดจริง (5 ก.ย. 2026) — **ยังไม่มีโค้ดในนี้**

## ข้อมูลที่ยืนยันแล้วจาก `01_เอกสารโครงการ/system_architecture.md`

| หัวข้อ | ค่า | อ้างอิง |
|---|---|---|
| บอร์ด | Raspberry Pi 5 · 5 V · 3–5 A · 15–25 W · ~50 g | §1.1 |
| สถานะ | **เฟส 2 — เฟส 1 ยังไม่เปิดใช้ Pi 5** | §1.2 |
| ลิงก์ไป ESP32 | UART: Pi 5 GPIO15 (RXD, ขากายภาพ 10) ↔ ESP32 GPIO43 | §3.7 |
| Level shifter | **ไม่ต้องมี** — ทั้งคู่ 3.3 V | §1.1 |

## ยังไม่ตัดสินใจ (อย่าเดา — ต้องถามผู้ใช้ก่อนเขียนโค้ด)
- รุ่นกล้องที่จะใช้ · เอนจิน OCR (Tesseract / PaddleOCR / อื่น) · ระบบปฏิบัติการบน Pi
- ยังไม่มีรายการนี้อยู่ใน BOM ที่ยืนยันแล้ว

## กติกา
- ล็อกเวอร์ชันไลบรารีใน `requirements.txt` เสมอ (Pi5 เป็น ARM64 — เครื่อง Mac/Windows ที่ dev ไว้อาจได้ wheel คนละตัว)

# MRC-001 — หุ่นยนต์อเนกประสงค์ (เก็บขยะ + อ่านมิเตอร์)

repo นี้ใช้ **ซิงก์งานข้ามเครื่อง**: Mac (เครื่องออกแบบหลัก) · Windows · Raspberry Pi 5 (ในอนาคต)

## ⚠️ ตั้งค่า 2 บรรทัดนี้ก่อนใช้งานทุกเครื่องใหม่

ชื่อโฟลเดอร์/ไฟล์ในโปรเจกต์นี้เป็น**ภาษาไทย** ถ้าไม่ตั้งค่านี้ ชื่อไฟล์จะโผล่เป็น `\340\270\201...` อ่านไม่ออก

```bash
git config core.quotepath false
git config core.precomposeunicode true
```

> `precomposeunicode` สำคัญเป็นพิเศษระหว่าง macOS ↔ Windows/Linux เพราะ macOS เก็บสระ/วรรณยุกต์ไทยแบบ decomposed (NFD) แต่ระบบอื่นใช้ NFC — ถ้าไม่ตั้ง Git จะเห็นไฟล์เดียวกันเป็นคนละไฟล์
> `.gitattributes` ในรากโปรเจกต์ประกาศไฟล์ binary (`.f3d .xlsx .pdf .stl .png`) ไว้แล้ว เพื่อกัน Windows แปลง CRLF จนไฟล์เสีย

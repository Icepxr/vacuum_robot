# ARIA หลังบ้าน — ต้นแบบ 10 ห้อง

เปิด [index.html](index.html) ในเบราว์เซอร์เพื่อดูต้นแบบแบบไม่ต้องติดตั้งแพ็กเกจหรือเริ่มเซิร์ฟเวอร์

ต้นแบบมีข้อมูลสมมติ 10 ห้อง (101–110), มิเตอร์น้ำและไฟห้องละหนึ่งตัว, ค่ารอยืนยัน 5 ค่า, ห้องว่างหนึ่งห้อง, ห้องยังไม่อ่านหนึ่งห้อง และห้องที่ไม่มีอีเมลหนึ่งห้อง ชื่อและอีเมล `example.com` เป็นข้อมูลตัวอย่าง

ลองกดเมนูทั้งห้า, ยืนยันหรือปฏิเสธค่ามิเตอร์, เปิด “รวมค่าเช่า”, ดูและอนุมัติบิล, จำลองส่งอีเมล, แก้อีเมลและค่าเช่าของห้อง 110 การเปลี่ยนแปลงอยู่ในหน่วยความจำของหน้าเว็บและหายเมื่อรีโหลด

**ต้นแบบนี้ไม่เชื่อม Pi 5, ESP32, Supabase, Google Sign-in หรือ Gmail และไม่ส่งอีเมลจริง** กติกาข้อมูลและส่วนที่ต้องต่อเพิ่มอยู่ใน [แบบออกแบบ v1](../aria-backoffice-v1.md)

## ARIA Orbit · 27 กันยายน 2569

ปรับภาพลักษณ์ทั้ง 5 หน้าโดยใช้โลโก้เดิม สีม่วงเข้ม/ลาเวนเดอร์ ดาวและเส้นวงโคจรแบบเบา ๆ พร้อมไอคอน SVG ในชุดเดียวกัน หน้าแรกแสดงวงความคืบหน้าจากจำนวนห้องในข้อมูลตัวอย่างจริงของต้นแบบ ไม่ใช่สถานะหุ่นสด มือถือใช้เมนูล่าง 5 หน้า; ตารางเลื่อนในกรอบของตัวเองเพื่อไม่ดันหน้าเว็บล้นจอ

`theme.css` แยกชั้นภาพลักษณ์จาก `styles.css` เดิม ไม่มีแพ็กเกจใหม่ ฟอนต์/CDN ภายนอก หรือการเรียก API เพิ่ม ฟังก์ชันยืนยันค่า อนุมัติบิล และจำลองส่งยังเก็บข้อมูลชั่วคราวในหน่วยความจำเหมือนเดิม

ตรวจเบราว์เซอร์: เมนูครบ 5 หน้าที่ความกว้าง 320, 390, 768 และ 1440 px ไม่ดันหน้าเว็บล้นแนวนอน; ตารางยังเลื่อนภายในได้ ทดสอบยืนยัน/ปฏิเสธค่า อนุมัติบิล เปิดค่าเช่าหลังอนุมัติแล้วบิลเดิมไม่เปลี่ยน และจำลองส่งสำเร็จ ไม่พบ console error ในการทดสอบนี้ ข้อมูลจำลองที่เปลี่ยนระหว่างทดสอบถูกรีโหลดกลับก่อนส่งมอบ

# MRC Motion Lab

เว็บจำลองการเคลื่อนที่ differential drive แบบ static ใช้ค่าตั้งต้นที่ผู้ใช้ยืนยันล่าสุด:

- ล้อ Ø87 mm
- ความหนาล้อ 40 mm
- track width วัดกึ่งกลางล้อ 260 mm
- encoder 2,464 counts/rev (ค่า nominal ที่เคยตรวจ M1)
- ความเร็วรอบอ้างอิง 178 rpm (no-load เดิม ยังไม่ใช่ค่าที่วัดบนพื้นจริง)

## เปิดใช้งาน

รันจาก root ของ repository เพื่อให้ browser อ่านไฟล์ STL ใน `05_CAD/` ได้:

```bash
python3 -m http.server 8765
```

จากนั้นเปิด <http://localhost:8765/motion-simulator/>

หน้าจำลองหลักยังทำงานได้หากเปิด `index.html` โดยตรง แต่ browser จะไม่ยอมให้โหลด STL ผ่าน `file://` จึงไม่เห็น CAD preview

## CAD และการประกอบ — แก้ไข 1 ต.ค. 2026

ภาพเริ่มต้นใช้ preview ที่ Fusion บันทึกไว้ใน assembly หลักของ `05_CAD/Asembly2.f3z` (root: `372321bd-628d-4569-92be-205b2725ff73.f3d`) จึงคงตำแหน่งประกอบของตัวถังและล้อจากไฟล์ต้นฉบับ ภาพนี้เป็นภาพนิ่ง ไม่ใช่การถอด geometry และ transforms จาก assembly

ปุ่มหุ่นจริงแสดงภาพสองภาพที่ผู้ใช้ส่งเพื่อเทียบตำแหน่ง blower, Pi, กล้องและชุดยก ภาพไม่ให้พิกัดมิลลิเมตรหรือยืนยันตำแหน่งติดตั้งแบตเตอรี่ถาวร

ตัวดู STL แสดงฐานล่างหรือชั้นบนทีละชิ้น แทนตัวดูเดิมที่รวมสอง STL โดยใช้พิกัดดิบผิด เนื่องจากไฟล์สองชิ้นใช้ origin ต่างกัน การทำ assembly สามมิติที่หมุนดูได้ทั้งชุดต้องได้ mesh ที่ export ในระบบพิกัด assembly เดียวกัน เช่น GLB หรือ STL รวมจาก assembly ก่อน สัญลักษณ์หุ่นบนสนามและล้อในแผนภาพ kinematics แสดงสมการที่จุดกึ่งกลางแกนล้อ ไม่ใช้ภาพอุปกรณ์เพื่ออนุมาน CoG

## ขอบเขตของแบบจำลอง

แผนภาพเรขาคณิตแสดงล้อ L/R, จุดกึ่งกลาง C, ระยะ B, รัศมี R, ทิศ θ และ ICC พร้อมลูกศรความเร็วแต่ละล้อ สเกลลูกศรความเร็วแยกจากสเกลระยะ รัศมีมีเครื่องหมายโดยบวกหมายถึง ICC ทางซ้ายของหุ่น กรณีวิ่งตรง ICC อยู่ที่อนันต์ และเมื่อหยุดทั้งสองล้อ ICC ไม่กำหนด

ใช้ exact differential-drive integration จากความเร็วล้อซ้ายและขวา สมมติพื้นราบ ล้อไม่ลื่น ไม่ยุบ คำสั่ง rpm เกิดทันที และ track width คงที่ จึงเหมาะกับการตรวจสูตรและสร้างค่าเริ่มต้น ไม่ใช่ผลรับรองการเคลื่อนที่จริง ต้องสอบเทียบ effective wheel diameter และ effective track width บนพื้นจริงอีกครั้ง

- **ทางลม (ผู้ใช้ยืนยัน):** ช่องใต้พื้น + แปรง → กล่องท้าย (รู Ø36 = จอ ถือว่าปิด) → ช่องตรง 25×50 → ถังขยะซ้ายสุด → รู Ø80 → blower ชั้นบน
- **หน้าตัด CAD:** `assets/airpath-sections.json` ตัดจาก `05_CAD/export_Newassembly/_all.stl` (มุมข้าง y = −62, มุมบน z = 20) · พื้นและแปรงวางตาม Asembly2 โดยประมาณ
- **อนุภาค:** เคลื่อนด้วยความเร็วเฉลี่ยของแต่ละช่วงจากแบบจำลอง 1 มิติ ช้าลง 40 เท่า · เศษไปถึงถังถ้า v ช่องตรง ≥ v_t · ลมยกเองได้ถ้า v ช่องใต้พื้น ≥ v_t ไม่งั้นแสดงเป็น "แปรงดีด" ซึ่งความเร็ว 3 m/s เป็นค่าแสดงผล ไม่ใช่ค่าคำนวณ · **ไม่ใช่ CFD**
- **ค่าที่ยังเป็นประมาณการ:** ΔP สูงสุด 423 Pa (เทียบ Delta BFB1012VH) · ระยะขอบถึงพื้น · ค่า K ทั้งหมด · ไส้กรอง
- **เศษปรับได้ (เพิ่ม 1 ต.ค. 2026 ตาม §22.11):** รูปทรงลูกบาศก์/ทรงกลม/ท่อนเส้นใย · ขนาด · C_d · μ · รอบและ Ø แปรง · ความสูงขั้น · มุมทางลาด · ค่าเริ่มต้นลูกบาศก์ 5×5×5 mm (ผู้ใช้ยืนยัน) C_d 0.8 → v_t 11.26 m/s → **ค้างที่ทางเข้า** ตรงกับอาการจริง · เกณฑ์: ทางเข้าผ่านถ้า v_slot ≥ v_t หรือแปรงดีดสูง v_tip²/2g ≥ ขั้น · ช่องตรงผ่านถ้า v_ch ≥ v_t√μ (ลากไถล)
